# 前端改版设计：Inkreel ／ 墨卷

日期：2026-10-31。分支：`langchain`。范围：`frontend/` 全部页面。后端不改。

## 0. 目标与决定

- **问题**：现在的界面像 demo，审美过时，功能散在多个页签里，用户得自己知道先做什么。
- **目标**：
  - 符合当下审美，高级感靠克制来实现。
  - 不看说明也知道下一步点哪里：整条流程是一条连贯的线，每屏只有一个主按钮。
  - 面向海外用户，上架给他人用。

| 决定 | 内容 |
|---|---|
| 产品名 | **Inkreel ／ 墨卷**，定位语 *From ink to reel.* 从文字到成片。名字集中放在一个配置里，改一处全站生效。上架前由用户自查域名与商标 |
| 语言 | 中英双语，右上角切换；默认按浏览器语言；所有界面文字进语言包 |
| 主题 | 深浅两套同等精修，默认跟随系统，可以手动切换，选择存在本机 |
| 技术 | Tailwind CSS v4、shadcn/ui（Radix）、`motion`、`lucide-react`；字体 Inter、Geist Mono，中文回落系统字体 |
| 路由 | 不引入路由库，沿用状态切换 |
| 先不做 | 价格页、可分享的网址、移动端专门设计（保证窄屏不乱） |

## 1. 架构

- **样式**：Tailwind v4 与现有 `index.css` 共存，逐页迁移，最后删除 `index.css`。设计变量（颜色、圆角、阴影、间距、字号）用 CSS 变量定义深浅两套，Tailwind 主题映射到这些变量。
- **品牌色**：墨色底，加一道琥珀到品红的渐变作为强调。每屏最多出现一种强调色。字号只用 3 级（标题、正文、辅助）。
- **组件**：shadcn 组件放在 `src/components/ui/`（按钮、卡片、页签、分段控件、对话框、下拉菜单、浮动提示、提示气泡、折叠面板、表格、骨架屏、徽章、进度条）。业务组件只用这一层，不直接写原生样式。
- **国际化**：`src/i18n/` 下放 `zh.ts`、`en.ts` 和一个很小的 `t()` / `useI18n()`。以中文语言包的键为准生成类型，英文缺键时编译报错；插值用 `{name}` 写法。语言选择存在本机。
- **品牌配置**：`src/brand.ts` 放产品名、定位语、标志。
- **逻辑不动**：`api.ts`、`useFilm`、`useCompose`、`useJob`、`useKeyframes`、`timeline.ts`、`film.ts`、`compose.ts` 等逻辑模块不改行为，只换界面层。

## 2. 首页（没登录时显示）

自上而下：

1. **顶栏**：固定在顶部，往下滚动后变成半透明磨砂。
   - 左边：标志和名字。
   - 中间：锚点链接「功能 / 流程 / 常见问题」，点了平滑滚动。
   - 右边：语言切换、主题切换、「登录」（次要按钮）、「免费注册」（主按钮）。
2. **首屏**：
   - 大标题 *From ink to reel*，副标题「把小说章节变成可编辑的分镜，再一键出片、配音、合成」。
   - 按钮「开始创作」打开注册，「看看流程」滚到流程段。
   - 背景是缓慢流动的渐变光斑，加一层细噪点。
   - 下方是代码绘制的「时间轴画布」示意图（不用截图），鼠标移过时有轻微视差，跟随主题和语言。
3. **功能**：6 张卡片，滚到时依次淡入上浮。
   - 小说转分镜
   - 完整性检查
   - 时间轴画布
   - 一键出片（多厂商、先试一段、花钱先确认）
   - 配音与合成（声画对齐、BGM、字幕）
   - 长期记忆（人物与主线跨章节保持一致）
4. **流程**：导入章节 → 生成分镜 → 画布上调整 → 出片与合成，4 步横向排列；滚动时步骤之间的连线逐段点亮。
5. **常见问题**：4–5 个折叠问答，包括费用怎么算、支持哪些模型、数据是否私有、能导出什么。
6. **结尾与页脚**：一句号召语加「免费注册」；页脚放版权和语言切换。

**登录 / 注册对话框**：
- 居中弹出，背景模糊；登录和注册用页签切换。
- 保留现有逻辑：注册时密码要输两次；还没有任何用户时默认打开注册。
- 错误提示显示在输入框下方。
- 登录成功后对话框收起，页面淡出，进入应用。

## 3. 应用外壳（登录后）

- **左侧边栏**（可以收起）：
  - 上面：标志和「新建小说」。
  - 中间：带搜索的小说列表，正在生成的小说旁边有一个转动的小圆点。
  - 下面：「管理后台」（只有管理员看得到）和账号头像菜单（语言、主题、退出登录）。
- **顶栏**：面包屑（小说名 / 章节 / 版本）；服务连不上时显示红色小标签。
- 切换页面时，内容区淡入、略微上移。

## 4. 章节工作流（易用性的核心）

### 4.1 步骤条

每个章节页顶部固定一条步骤条：

> ① 导入原文 → ② 生成分镜 → ③ 检查修改 → ④ 出片 → ⑤ 配音合成 → ⑥ 下载成片

- 已完成的步骤打勾，当前步骤高亮，没到的步骤变灰。点灰掉的步骤会说明「需要先完成第几步」，并给出直达按钮。
- 进入章节时自动停在「该做的那一步」。判断逻辑写成纯函数 `currentStep(chapter, version, film, compose)`，按顺序取第一个没完成的步骤：
  1. 没有原文 → ①。
  2. 没有成功的分镜版本 → ②。生成中也停在 ②，并显示进度。
  3. 有未保存的修改，或完整性检查没过 → ③。
  4. 还没有出片会话，或还有段没出 → ④。
  5. 没有成片，或成片已过期 → ⑤。
  6. 都完成了 → ⑥。
- 各步对应的工作区：
  - ① 原文：现在的原文视图。
  - ② 生成：参数和进度。
  - ③ 检查修改：时间轴画布为主，卡片和资产视图是它的切换项。
  - ④ 出片、⑤ 配音合成：在画布里，侧栏自动打开对应面板。
  - ⑥ 下载：每集的成片、字幕和合成报告。

### 4.2 每屏一个主按钮

- 每一步右下角固定一个主按钮，写明动作和金额，比如「生成分镜」「先试一段（约 ¥5）」「合成整章（配音约 ¥0.18）」。其他操作都用次要样式。
- 主按钮不能点时，按钮上方写原因，并给一个修复按钮。修复按钮滚到对应位置并高亮 1.5 秒。原因沿用现有逻辑（`composeBlockers`、出片的验证门和未保存判断），只加上「去修复」的定位目标。

### 4.3 说人话

- 界面上不出现内部术语：
  - 「IR」→「分镜」
  - 「验证门」→「完整性检查」
  - 「指纹 / 过期」→「内容改过，需要重新生成」
  - 「草稿合成」→「没出好的段先用图片代替」
- 关键概念旁边放一个「?」，鼠标移上去显示一句解释。

### 4.4 连贯与安全感

- **花钱的确认**：全站用同一个确认对话框组件。金额加粗，并写明已花、执行后累计和上限，以及费率依据。
- **未保存的修改**：底部固定一条提示条「有未保存的修改 · 保存 · 撤销」，切换页面、离开章节前会提醒。保存仍然是手动的。
- **耗时任务**（生成分镜、出片、合成）：显示进度和预计剩余时间。可以离开这一页，侧栏圆点和浮动提示会在完成时通知，点通知回到结果。
- **完成反馈**：每一步完成时打勾动画，加一句结果，比如「分镜已生成，共 133 镜」，然后下一步的主按钮亮起。
- **新手引导**：第一次进入时显示 3–4 个可跳过的提示气泡（新建小说、导入章节、看进度）。看过的记录存在本机。
- **空状态**：插图加一句话加按钮，比如「还没有小说，从导入第一章开始」。

## 5. 各页面换装（功能不变）

- **小说页、章节页**：章节卡片网格，带状态徽章和进度条，生成中的卡片显示骨架屏；资产卡带缩略图。
- **分镜视图**：镜头卡片重新排版，景别、运镜做成小标签，旁白和台词分层显示；视图切换用分段控件。
- **时间轴画布**：
  - 只换配色、描边和悬停效果：泳道配色统一，选中的镜头发光描边，播放头更醒目，底部工具条做成悬浮的胶囊形。
  - SVG 绘制与拖动、缩放的交互不改。
  - 侧栏用 shadcn 页签；出片与合成的确认框换成第 4.4 节的统一对话框。
- **管理后台**：用户表格支持排序、搜索；用量用卡片加迷你折线图展示。
- **全局反馈**：
  - 文字提示改成右下角的浮动提示（toast）。
  - 加载状态一律用骨架屏。
  - 删除、覆盖等危险操作统一走确认对话框。

## 6. 动效

- 时长 150–400 毫秒，用缓出曲线。动效只用来解释状态变化（进场、展开、完成、出错），不做装饰性的循环动画；首屏的背景光斑除外，它很慢。
- 列表和卡片依次进场，每个间隔 30–50 毫秒。对话框缩放加淡入；页面切换时淡入并上移 8 像素。
- 系统开了「减少动态效果」（`prefers-reduced-motion`）时，关掉所有位移和视差，只保留淡入淡出。

## 7. 拆分（依次进行，每个子计划做完都能用、测试全过）

1. **底座**：
   - 依赖与 Tailwind / shadcn 配置。
   - 深浅主题与品牌色。
   - 语言包框架与 `brand.ts`。
   - 通用组件：浮动提示、统一确认对话框、骨架屏、「?」解释、提示气泡。
   - 新的应用外壳：侧边栏、顶栏、主题与语言切换。
2. **首页和登录注册对话框**。
3. **章节工作流**：
   - 步骤条与 `currentStep`。
   - 小说页、章节页换装。
   - 主按钮加原因加修复按钮。
   - 未保存提示条、耗时任务通知、完成反馈。
4. **分镜视图、时间轴画布、出片与配音合成面板换装**。
5. **收尾**：管理后台换装、新手引导与空状态、补齐英文翻译、删除 `index.css`。

## 8. 测试与验收

- **现有测试**：9 套前端测试在每个子计划结束时都必须通过。测试里定位元素用的 class 名同步改成稳定的 `data-*` 属性或保留原名；断言里的中文文字随语言包调整，测试固定用中文。
- **新增测试**：
  - 语言包完整性：中英文键一致，用类型检查加一个运行时比对。
  - 首页能用中英文渲染出来。
  - 登录、注册对话框的流程：两次密码不一致时拦截，还没有用户时默认打开注册。
  - `currentStep` 在各种章节状态下的结果（纯函数）。
  - 主按钮不能点时的原因和修复目标。
  - 「减少动态效果」打开时不出现位移动画。
- **lint**：0 个错误。
- **验收**：每个子计划做完，在本地启动服务（假出片厂商、假配音，不花钱），列出要看的页面，由用户判断观感和顺手程度。不满意的在当个子计划内改。
