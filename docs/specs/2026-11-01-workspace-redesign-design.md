# 工作台改版设计：从「能用」到「专业创作工具」

日期：2026-11-01。分支：`langchain`。范围：`frontend/` 的书架、新建、小说、章节几个层级，后端只加一个汇总接口（第 9 节）。

前置：`docs/specs/2026-10-31-frontend-redesign-design.md`（Inkreel／墨卷 改版，5 个子计划已完成）。本设计沿用它的设计变量、组件层（shadcn）、中英双语、深浅主题、动效规则，只改**信息架构与页面布局**。

## 0. 问题与目标

- **问题**：用户反馈界面「还和 demo 一样」。表单是一列列原生下拉，没有层次；进了一部小说之后，左边仍然只是小说列表，看不出这部小说做到哪了、花了多少钱、有哪些角色。
- **目标**：
  - 看起来和用起来都像一个成熟的创作工作台。参照对象是 ArcReel 和阅文 漫剧助手。
  - 进入任何一层都能一眼看到「在哪、做到哪、花了多少、下一步点哪」。
  - 新建入口以「贴原文」为主角，参数退到次要位置。
- **不变**：
  - 后端的转换、出片、合成逻辑，以及前端的 `api.ts`、`workflow.ts`、`timeline.ts`、`useFilm`、`useCompose` 等逻辑模块。
  - 章节工作流的 6 步判定（`currentStep`）。
  - 时间轴画布的绘制与交互。

## 1. 竞品要点

| 竞品 | 我们借鉴什么 | 不借鉴什么 |
|---|---|---|
| **ArcReel**（开源，[GitHub](https://github.com/ArcReel/ArcReel)） | 见下方列表 | 多厂商配置页；导出剪映草稿（列入以后） |
| **阅文 漫剧助手**（[aicomic.yuewen.com](https://aicomic.yuewen.com/)） | 拆书概览：一句话梗概、世界观、人物分析，对应我们的主线剧情、资产卡、章节摘要；整剧推进，即批量看各集进度 | 无限节点画布、团队额度与权限、剧本市场、局部重绘 |
| **LTX Studio** | 新建分两条路：「从剧本 / 原文开始」；在设置页定画幅、风格、演员；风格参考图 | 风格参考图（后端不支持，列入以后） |
| **Lovable、ChatGPT 的首页输入框** | 大输入卡片是首页主角；参数收成卡片底部的胶囊；模板卡片放在输入框下方 | — |
| **Sora、Kling 创作页** | 画幅、风格预设先选好，带可视化预览（比例框、风格卡） | — |

ArcReel 借鉴的部分：
- **顶栏**：左边是项目切换（项目名下面写「DRAMA · 9:16」）。中间是阶段胶囊（准备 / 脚本 / 制作 / 完成）。右边是费用表、通知、导出。
- **左栏**：项目概览、源文件、角色集、场景库、道具库，每项带数量。下面是分集卡片列表，带编号方块、状态、进度、时长和一条进度细线。
- **集页头部**：大标题，旁边「预估 / 已花 / 剩余」三格金额。
- **三栏编辑**：左边是镜头列表（缩略图加状态），中间是编辑，右边是预览加一个通栏主按钮。
- **新建时选模式**：「旁白 / 剧情」二选一。
- **右侧 Agent 面板**：显示正在跑的任务和进度。

## 2. 信息架构

```
书架（没选小说）                      小说工作台（选了一部）
┌────────┬──────────────────┐        ┌────────┬───────────────────────┬────────┐
│ 小说列表│ 新建输入卡片       │        │ 项目导航│ 概览 / 章节 / 资产 / …  │ 动态面板 │
│ (搜索)  │ 最近的小说（卡片网格）│        │ 章节卡片│                       │ (可收起) │
└────────┴──────────────────┘        └────────┴───────────────────────┴────────┘
```

- **书架**：没打开任何小说时显示（含首次登录）。左栏是小说列表，主区是新建卡片加最近小说的卡片网格。
- **小说工作台**：打开一部小说后，**左栏变成这部小说的项目导航**，不再是全部小说的列表。
  - 小说之间的切换挪到顶栏左侧的「项目切换器」。这和 ArcReel 一致，也是本次「去 demo 感」的关键一步。
  - 右侧新增可收起的「动态面板」（第 7 节）。
- 路由仍沿用状态切换，不引入路由库（与前置设计一致）。

## 3. 顶栏（全局，高 56px）

```
[◧] [墨卷] / [药 ▾ 9:16 · 写实]        [① 导入 ② 分镜 ③ 检查 ④ 出片 ⑤ 配音 ⑥ 下载]        [¥3.66 · $0.40] [🔔2] [文/A] [◐] [头像]
```

- **左**：
  - 侧栏开关、标志。
  - **项目切换器**：小说名加一行小字「9:16 · 写实」，点开是下拉，里面有搜索、最近小说和「＋ 新建小说」。
  - 在章节里时，后面接「/ 第三章 ▾」，可以切换章节。
- **中**：只在章节里显示。现在章节页顶部的步骤条挪到这里，做成紧凑的胶囊分段控件：带编号，已完成的显示勾，当前步高亮。
  - 行为不变：点灰掉的步骤会说明原因，并给出直达按钮。
  - 窄屏时收成「③ 检查修改 ▾」。
- **右**：
  - **费用表**：小说层显示这部小说的累计花费，章节层显示本章；点开浮层看明细（大模型 / 出片 / 配音，已花与上限）。数据来自第 9 节的汇总接口。
  - **铃铛**：数字表示正在跑的任务数，点它展开右侧动态面板。
  - 语言、主题、账号头像菜单（退出、管理后台）。
  - 服务连不上时，铃铛左边显示红色小标签。现在的模型名徽章挪进账号菜单，不再占顶栏。

- **上半部分是固定导航**，对应现在小说页的各个页签：
  - 「资产库」拆成角色 / 场景 / 道具 / 生物四个入口，与 ArcReel 一致。
  - 「人物状态」与「主线剧情」合成「剧情与记忆」。
  - 「参数」改名「设置」。
- **下半部分是章节卡片列表**：
  - 编号用等宽字放在小方块里，后面是标题。
  - 第二行是这一章当前所在的步骤名（来自 `currentStep`），以及时长或镜头数。
  - 底部一条 2px 进度细线，按 6 步完成了几步算。
  - 生成中的章节显示脉动圆点。当前章节有 `--primary` 左竖条。
- 收起时只剩图标和章节编号方块，鼠标悬停显示名字。

```
  ┌────────┐ ┌────────┐ ┌────────┐
  │ 渐变封面 │ │        │ │        │

  └────────┘ └────────┘ └────────┘
```

### 主卡片

- **旁白 / 剧情二选一**：对应现有的旁白模式，后端参数不变。
  - 「旁白解说」对应 `selective`。
  - 「剧情演绎」对应 `none`。
  - 「更多」里仍可细选 4 种旁白模式（原文照念、择要旁白、压缩概述、无旁白）。
  - 选了细项以后，二选一卡片显示为对应的那一张；如果细项是「原文照念」或「压缩概述」，旁白卡片上加一个角标，写明具体模式。
- **拖放导入**：拖 .txt 到卡片上，卡片描边高亮并显示「松手导入」。读入文件时，标题为空就用文件名。
- **章节识别结果**：显示成一排小标签，超过 4 个折叠成「+N」，点开看全部。
- **主按钮**：标题没填时不能点，旁边写「先给小说起个名字」。按钮文字是「创建小说」，导入了章节时写成「创建并导入 N 章」。

### 胶囊（shadcn Popover）

- **画幅**：4 个按真实比例画的小框，9:16、16:9、1:1、4:3。
- **风格**：与下方的风格卡片联动，显示当前选中的风格。
- **音色**：5 个音色，每项一句描述（例如「男声 · 沉稳，适合正剧旁白」）。
- **更多**：色调、目标平台、风格前缀（可自由输入，下面列出常用写法）、旁白模式细项。

### 风格卡片

- 宽约 112px、高 72px，用代码画的渐变或纹理色块，不用图片，下面写名字。每种风格一套配色：
  - 写实：中性灰褐。
  - 电影：青橙。
  - 动漫：高亮粉蓝。
  - 水墨：黑白宣纸噪点。
  - 国漫：朱红金。
  - 油画：厚涂暖色。
  - 水彩：淡彩晕染。
  - 3D：高光渐变。
  - 像素：方格。
- 选中时 2px `--primary` 描边，右上角打勾。
- 选中某个风格时，同时带出一句默认的风格前缀；如果用户已经手改过前缀，就不覆盖。
- 「＋自定义」打开「更多」，焦点放到风格前缀上。
- 用户可以给任一张风格卡片换上自己的图片（悬停出现「换图」），存在本机浏览器，有图用图、没图用色块，可恢复默认。只换卡片的显示图，不参与生成；当作风格参考图发给模型的功能以后另做（第 11 节第 4 条）。

### 最近的小说

- 卡片网格。封面是按这部小说的风格画的渐变色块，加书名首字。
- 卡片上写：章节数、已采用数、最后编辑时间。
- 生成中的小说，卡片右上角显示脉动圆点。
- 最后一张卡片是「＋ 新建」，点了滚回顶部，聚焦标题输入。

### 共用组件

小说「设置」页用同一套胶囊和风格卡片组件，只是排成竖版的设置表单：左边是标签和说明，右边是控件。

```
└──────┘└──────┘└──────┘└──────┘└──────┘└──────────────┘

故事梗概（主线剧情）                     主要人物
┌──────────────────────────┐   ┌──┐ 华老栓  茶馆老板 · 出场 4 章

```

- **继续按钮**：右上角「继续」直达最近编辑的那一章，并停在它该做的那一步（沿用 `currentStep`）。
- **数字卡**：章节、已采用、镜头总数、资产卡总数、已成片（几章 / 共几章）、累计花费。镜头数和成片数来自第 9 节的汇总接口。
- **故事梗概**：取主线剧情的前几行，旁边是「编辑」按钮。对应阅文的「一句话梗概」。
- **主要人物**：按出场章节数取前 5 个角色，头像用参考图，没有参考图就用首字圆形头像。
- **章节进度**：每章一行，6 个小格对应 6 步，后面写「当前步骤 · 一句状态」，最右边是时长。点一行进入那一章。
- **待处理**：把需要人处理的事集中在这里，例如待确认的人物状态、内容改过需要重新生成的成片。
- 现在小说页的「章节」卡片网格页签取消，章节列表由左栏和这一页的「章节进度」承担。「新章节」入口放在左栏章节标题旁的「＋」，以及「原文与章节」页。

## 7. 右侧动态面板（宽 320px，默认收起，铃铛打开）

- **在跑**：列出正在跑的任务，包括生成分镜、出片、合成。每项写所在小说和章节、进度条、预计剩余时间、最新一行日志（等宽字），以及「查看」按钮。
- **最近完成**：最近 20 条结果，点了直达那一章、那一步。现在的右下角 toast 照常弹出，这里留作历史。
- 数据来自现有的任务列表接口和 `useJob`、`useFilm`、`useCompose`，不加后端接口。
- **为 Agent 面板预留**：面板顶部预留页签位置，以后加「助手」页签。Agent 对话本身不在本设计范围，见第 12 节。

## 8. 章节工作台

### 8.1 章节头部（所有步骤共用）

```
EP·03  第三章                         预估        已花        上限
45 镜 · 约 4:45 · ● 检查修改           ¥5.44      ¥3.66      ¥20.00
```

- 编号等宽小徽章、标题大号字、一行状态小字。
- 右边三格金额来自出片会话：还没有出片会话时显示「—」，并写「出片时才会花钱」。
- 头部下方是步骤对应的工作区，步骤条在顶栏。

### 8.2 ③ 检查修改：新增「镜头」三栏视图，成为默认视图

```
┌ 镜头 45 ─────────┐┌ E01-SH012 · 中景 · 推 · 4.0s ──────────┐┌ 预览 ────────────┐
│[搜索镜头…]        ││ 画面描述                                ││ [关键帧 / 成片段]  │
│ ▣ SH011 ● 原文    ││ 旁白 / 台词                              ││                  │
│ ▣ SH012 ● 系统补充 ││ 角色表演 …（现有 ShotCard 的编辑控件）     ││ 原文出处 3 句      │
│ ▣ SH013          ││                                        ││ ──────────────── │
│ …                ││                                        ││ [ 在画布中查看 → ] │
└──────────────────┘└────────────────────────────────────────┘└──────────────────┘
```

- **左栏（280px）**：镜头列表，按集分组，可折叠。每项内容：
  - 缩略图：有关键帧就显示，没有就显示景别色块。
  - 镜头 ID（等宽字）。
  - 来源标签：原文明写、系统补充、过渡镜，沿用现有语义色。
  - 时长。
  - 完整性检查有问题的镜头，带红色小圆点。
- **中栏**：选中镜头的完整编辑，复用现有的 `ShotCard` 编辑态，排版成上下分区。
- **右栏（320px）**：
  - 关键帧大图。出过片时可以切到成片段视频。
  - 这一镜引用的原文句子。
  - 底部是通栏主按钮：没有未保存修改时写「在画布中查看」；有未保存修改时写「保存修改」，与底部的未保存提示条联动。
- **视图切换**：「镜头 / 卡片 / 资产 / 原文 / 渲染 / JSON」做成分段控件，默认是「镜头」。现有的卡片视图保留，作为第二项「卡片」。
- **窄屏（<1100px）**：右栏收进中栏下方；小于 760px 时只显示列表，点一项进入编辑。

### 8.3 ④ 出片、⑤ 配音合成：不改

时间轴画布照旧，只在画布顶部加上 8.1 的章节头部（精简成一行）。

### 8.4 ① 导入原文、② 生成分镜、⑥ 下载：只换版式

都放进 8.1 的头部下面，用居中最宽 880px 的卡片，主按钮在卡片右下角。逻辑不变。

## 9. 后端：只加一个汇总接口

`GET /novels/{nid}/summary`（需要登录，只能读自己的小说），返回：

```json
{
  "cost": { "llm_usd": 0.40, "film_cny": 3.66, "tts_cny": 0.02 },
  "chapters": [
    { "id": "c1", "shots": 45, "duration_s": 285, "film": { "done": 9, "total": 9 },
      "final": "fresh", "cost": { "llm_usd": 0.12, "film_cny": 1.20, "tts_cny": 0.01 } }
  ]
}
```

- 各字段的来源：
  - `llm_usd`：用量记录里已有 `novel_id`，按它汇总（用 `pricing` 估价，与管理后台一致）。
  - `film_cny`、`tts_cny`：各章采用版（没有采用版就用最新版）的出片会话里的已花金额。
  - `shots`、`duration_s`：采用版的镜头数和时长。
  - `final`：取值 `none`、`fresh` 或 `stale`。
- 只读，不改任何现有接口。读不到的字段返回 `null`，前端显示「—」。
- 用途：费用表、概览页的数字卡和章节进度、左栏章节卡片的进度线。不用这个接口，就得逐章拉出片会话，请求太多。

## 10. 视觉规则补充（让界面像专业工具）

- **信息密度**：工作台内正文 13–14px，行高 1.5。列表行高 36–44px。卡片内边距 12–16px。书架和新建页保持宽松（16–20px）。
- **等宽字**：所有 ID、编号（EP·03、SH012）、时长、金额、字数一律用 Geist Mono 加 `tabular-nums`。
- **状态标签**统一成一个组件 `StatusPill`：圆点加文字，底色是语义色的 12% 透明度。四种：成功 `--success`、进行中 `--primary` 加脉动、警告 `--warning`、失败 `--destructive`。全站的状态显示都换成它。
- **缩略图**：凡是有图的地方都显示图，包括资产卡参考图、关键帧、成片尾帧；没有图时用对应类别的渐变色块，不留空白。
- **主按钮**：每屏一个，放在卡片右下角或预览栏底部（通栏）。其余按钮用 `outline` 或 `ghost`。
- **强调色**：品牌渐变只用在主按钮、当前步骤和选中态。工作台底色保持中性，深色主题用 slate 系，不另加新的主色。
- **动效**：沿用前置设计第 6 节。新增：
  - 左栏导航切换时，内容区淡入。
  - 动态面板从右侧滑入，持续 240ms。
  - 进度细线变化时，宽度过渡 300ms。
